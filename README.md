## 💍 About the Project

Egale is a digital wedding invitation project focused on creating
an elegant online experience for wedding invitations.

The project is hosted using GitHub Pages and connected to a
custom domain.

## ✨ Features

- Elegant digital wedding invitation experience
- Responsive design for mobile and desktop devices
- Custom domain integration
